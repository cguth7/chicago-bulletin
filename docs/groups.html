The ledger — why a quiet group still counts

Filed once, then kept honest

Groups outlive any single week. The directory keeps the group even when it has nothing on, because that is the truthful state:

  • Filed — a group enters the ledger the first time a lead or an event names it
  • Resolved — every event lands against one group record, never a duplicate
  • Vetted — a human or agent confirms it is real before its events go public
  • Live — live means a built pipeline is watching, not that this week is busy
