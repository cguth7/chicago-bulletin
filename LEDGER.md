# Ledger

The running log of this Bulletin, and the memory between sessions: the funnel
says what's stuck *now*; this says what happened, what was tried, and what was
decided. `/next` reads the last entry before it starts and appends one when it
finishes. Newest entries at the bottom.

Each entry: a dated heading, then a few honest lines —
- **Ran:** which stage, which agents, on what (e.g. "Scout sweep, 18 sources").
- **Funnel:** before → after (built, visible, scored — real numbers).
- **Decided / learned:** anything the next session must not re-litigate
  ("skip the suburbs", "Do312's venue pages beat its main feed").
- **Left off:** what's half-done, if anything.

Lessons that keep mattering belong in the doc that actually gets read (an agent
charter, `engine/CLAUDE.md`), not only here. When this file gets long (~400
lines), move the oldest entries to `LEDGER-archive.md` and leave a few lines of
summary in their place.
